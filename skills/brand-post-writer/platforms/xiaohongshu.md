# 小红书 Xiaohongshu —— 品牌官方撰写规则（模块化）

产出装配为 `SaveContent` 工具 `content` 入参中的四个模块：`meta` / `caption` / `hashtags` / `images`。

## `meta`

- `title`：小红书笔记标题，**必填**
  - 建议 12–20 个中文字符
  - 必须清楚表达内容主题
  - 优先包含用户场景、问题、关键词或利益点
  - 不使用无法证明的绝对化表达
  - 避免标题：
    - 全网最值得买
    - 真的绝了
    - 不买后悔
    - 100%有效
    - 第一名就是它
    - 彻底解决你的问题
- `language`：默认 `zh-CN`
- `cta`：CTA 应根据内容类型选择，不应每篇都强销售；不要把合规披露塞进这里
  - 避免：
    - 快去买
    - 赶紧冲
    - 不买亏了
    - 最后一波
    - 错过后悔
    - 全网最低
- `mentions`：品牌官方号或合作方 @handle（若 Brief 指定）
- `location`：可留空

## `caption`

- `body`：**必填**，正文长度不应固定，应根据内容类型调整；2–3 行一段，口语但保持品牌可信度
  - 短种草 / 日常场景类：
    - 建议长度：80–250 字
    - 适合：日常使用场景、生活方式内容、单个产品轻介绍、品牌氛围内容
  - 产品说明 / 新品介绍类：
    - 建议长度：200–500 字
    - 适合：新品发布、产品功能说明、产品设计理念、产品系列介绍
    - 不要把正文写成详情页
    - 不要一次性堆太多卖点
    - 每篇笔记只聚焦 1–3 个重点
  - 教程 / 攻略 / 清单类：
    - 建议长度：400–900 字
    - 适合：使用教程、选购指南、搭配指南、避坑内容、知识科普
  - 品牌故事 / 品牌观点类：
    - 建议长度：300–700 字
    - 适合：品牌理念、设计故事、幕后内容、活动回顾、主理人/团队视角
    - 不要空泛讲价值观
    - 不要写成品牌宣传稿
    - 必须有具体细节支撑
  - 品牌官方账号口吻：
    - 来自品牌，但不端着
    - 专业可信，但不说教
    - 有生活感，但不伪素人
    - 有产品信息，但不强行推销
    - 能帮助用户做判断，而不是单纯宣传品牌
  - 品牌露出建议：
    - 品牌项内容的标题和首段内容中，一定要包含品牌名或产品名
    - 正文中可以自然出现品牌名
    - 产品发布、活动、新品、福利类内容可以明确品牌露出
    - 生活方式、科普、指南类内容可以弱化品牌露出
  - 避免：
    - 每段都出现品牌名
    - 反复强调“我们品牌”
    - 强行把所有生活场景都导向产品
    - 用品牌口号替代真实内容
  - 产品卖点必须具体、真实、可理解。
  - 推荐表达：
    - 适合什么场景
    - 解决什么小问题
    - 和用户生活有什么关系
    - 为什么这个设计有必要
    - 使用前后体验有什么差异
  - 避免表达：
    - 空泛形容词堆叠
    - 高级、极致、顶级、天花板
    - 行业第一、全网第一、最好
    - 彻底解决、永久改善、100%有效
    - 没有证据的数据和结论
  - 严禁绝对化用语：最好 / 第一 / 顶级 / 极致 / 天花板 / 100% / 永久 / 彻底 / 根治 / 保证有效 等
  - 医疗、功效、化妆品：不承诺疗效，不使用未验证数据
- `variants`（可选）：若用户要 A/B，主版放 `body`，备选版放 `{label, body}`
- `tone_notes`：内部语气备忘，一两句即可

## `hashtags`

- `items`：**不带 `#` 前缀**，由渲染端拼接
  - 建议 3–6 个
  - 最多不超过 10 个
  - 不使用与内容无关的热门话题
  - 不重复堆叠同义词
  - 不用过多宽泛大词
  - 推荐组合：
    - 品类词
    - 场景词
    - 人群词
    - 品牌词
    - 内容主题词
  - 品牌词不是每篇都必须出现
  - 产品发布、活动、新品内容建议出现品牌词
  - 知识科普、生活方式内容可以弱化品牌词
- `placement`：`"inline"`（正文末尾）
- `max`：10

## `images`

- `style`：整组图的视觉总纲，一段 2–4 句话，覆盖色调 / 光线 / 氛围 / 场景类型 / 拍摄感 / 文字叠加风格，并遵循品牌 `visual_guidelines`
- `aspect_ratio`：默认 `"3:4"`；推荐优先级：
  - 竖版 3:4：小红书图文笔记优先推荐比例
  - 其他比例：不建议作为常规发布素材，可能出现裁切或信息展示不完整
- `recommended_size`：按图片类型选择推荐尺寸
  - 竖版图文：3:4，1080 × 1440 px
  - 高清竖版封面：3:4，1242 × 1660 px
- `format`：内部建议支持 JPG / JPEG、PNG、WebP
  - 摄影图、生活方式图、产品图：优先 JPG / JPEG
  - 需要透明背景的素材：使用 PNG
  - WebP 可用于压缩体积，但发布前应测试兼容性
  - 不建议将 GIF 作为常规图文素材标准
- `file_size`：内部交付建议
  - 单张图片建议不超过 10 MB
  - 常规发布图建议控制在 1–5 MB
  - 长图或高清视觉图可适当提高，但发布前需要压缩测试
  - 不建议上传过度压缩、明显模糊、文字锯齿明显的图片
- `items`：**4–8 张**，顺序即图序
  - 第 1 张必为 `"cover"`，首图主体明确，信息层级清楚
  - 封面文案应更短、更直观，帮助用户一眼理解内容。
  - 封面文案建议 6–14 个中文字符
  - 一张封面只表达一个核心信息
  - 不使用过度夸张词
  - 不制造焦虑
  - 不承诺无法证明的结果
  - 中间为 `"content"`，承载卖点、场景、细节、使用演示或对比
  - 最后一张可为 `"closing"`，承载 CTA 或总结
  - `prompt`：必须包含主体 + 场景 + 构图 + 光线 + 色调 + 风格；如有文字叠加需写清文案与字体风格
  - `alt`：一句中文描述
  - 必须满足：
    - 画面清晰，不糊、不虚焦
    - 文字可读，不被裁切
    - 首图主体明确，信息层级清楚
    - 同一组图片风格、色调、比例尽量统一
    - 重要文字和主体避开边缘，避免被平台裁切或遮挡
    - 不出现无授权水印、Logo、肖像或版权素材

## 自检清单

- `meta.title` 是否清楚？
- `caption.body` 是否像品牌官方号，而不是伪素人？
- `caption.body` 是否过度销售？
- `caption.body` 是否只引用 Brief / 产品矩阵中的事实？
- 是否避开品牌护栏 forbidden_terms？
- 是否有无法证明的绝对化表达？
- 是否有医疗、功效、收益等高风险承诺？
- 是否自然出现用户场景？
- 是否每篇只聚焦 1–3 个重点？
- `hashtags.items` 是否相关？
- `meta.cta` 是否符合内容类型？
- 是否需要补充合规提示？
- `images.aspect_ratio` 是否符合内容类型？
- 图片是否清晰？
- 图片文字是否可读？
- 图片主体是否被裁切？
- 图片容量是否过大？
- 图片格式是否兼容？
- 图片是否有水印、第三方 Logo、版权风险？
- `images.items[0].role == "cover"` 且 prompt 写清封面字？
