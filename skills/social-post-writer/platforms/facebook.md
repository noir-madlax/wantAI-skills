# Facebook —— 撰写规则

## 结构

- **开头**：一句停留钩子（提问 / 反常识 / 场景切入）
- **长度**：两种常用形态
  - 短互动帖：80–150 字，口语对话感
  - 故事长帖：300–600 字，完整叙事弧
- **段落**：短段落 + 空行；避免大块堆叠

## Hashtags

- 1–3 个即可，不堆砌（过多反而降低触达）
- 放在正文末尾

## CTA

- 结尾**抛一个具体问题**促评论（例：你会选 A 还是 B？）
- 外链单独一行放最末，避免裸链接型内容
- 不要在开头贴链接

## 语气

- 贴合 KOL `voice`，叙事、对话感，受众年龄普遍偏成熟
- 避免过度使用 emoji；1–3 个即可

## 版本差异

- **版本 A（稳）**：故事长帖，情感铺陈 + 结尾提问
- **版本 B（钩子）**：短互动帖，直接抛反常识观点 / 二选一

## 输出字段

```
## Facebook · 版本 {A|B}
- 正文（{字数}字）：
  …
- Hashtags：#…
- 结尾提问：…
- 链接（如有）：…
- 备注：{披露 / 假设}
```
