# Facebook —— 撰写规则（模块化）

产出装配为 `SaveContent` 工具 `content` 入参中的四个模块：`meta` / `caption` / `hashtags` / `images`。

## `meta`

- `title`：**留空**（FB 没有独立标题字段）
- `language`：默认按 KOL `audience_signals` 主要市场语言；无信息则 `en`
- `cta`：一个**具体问题**，促评论（例：你会选 A 还是 B？）；外链单独放 `caption.body` 末行
- `mentions`：品牌/合作方页面 @handle
- `location`：可按 Brief 填

## `caption`

- `body`：**必填**，两种常用形态任选其一（与 Brief 目标匹配）：
  - **短互动帖**：80–150 字，口语对话感，开头即钩子
  - **故事长帖**：300–600 字，完整叙事弧（开头钩子 → 情境 → 转折 → 收束提问）
  - 开头第一句必须是停留钩子（提问 / 反常识 / 场景切入），**不要**把链接放开头
  - 短段落 + 空行，避免大块堆叠；emoji 1–3 个足够，避免过度使用
  - 合作/返佣关系按 Brief 合规项显式披露
  - 外链单独一行放最末
- `variants`（可选）：若用户要 A/B，`body` 放故事长帖（情感铺陈 + 结尾提问），`variants` 放短互动帖（反常识观点 / 二选一）
- `tone_notes`：一两句内部语气备忘；受众年龄普遍偏成熟

## `hashtags`

- `items`：**1–3 个**，不带 `#` 前缀；过多反而降低触达
- `placement`：`"inline"`（正文末尾）
- `max`：3

## `images`

FB 图片是触达放大器，质量优先；不鼓励多图轮播。

- `style`：一段 2–4 句话，覆盖 **色调 / 光线 / 真实感 vs 设计感 / 是否带文字卡片**；整体风格宜偏**真实、生活化、可信**，避免过度修饰的"广告感"
- `aspect_ratio`：默认 `"1:1"`；横图场景用 `"1.91:1"`（link preview / 横幅）
- `items`：**1–3 张**；顺序即展示顺序
  - `role`：
    - 第 1 张必为 `"cover"`（主图，停留钩子，可带文字卡片承载核心观点/问题）
    - 可选 `"content"`（场景/细节/对比）
    - 可选 `"closing"`（CTA 图/链接卡片），可省略
  - `prompt`：必须包含 **主体 + 场景 + 构图 + 光线 + 色调 + 风格**；带文字卡片的图要写清文案与排版风格
  - `alt`：一句话描述

## 自检清单

- 开头第一句是否是钩子（非链接、非自我介绍）？
- `meta.cta` 是否是具体问题？
- 外链是否单独放在 `caption.body` 末行？
- `hashtags.items` 是否 ≤ 3 个？
- `images.items` 是否 ≤ 3 张且第 1 张为 `cover`？
