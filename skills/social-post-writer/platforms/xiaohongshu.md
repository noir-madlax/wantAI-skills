# 小红书 Xiaohongshu —— 撰写规则（模块化）

产出按 `SaveContent` 工具的四个模块装配：`meta` / `caption` / `hashtags` / `images`。

## `meta`

- `title`：**必填**，≤ 20 字；含 emoji + 钩子（数字 / 身份标签 / 反转 / 悬念）
- `language`：默认 `zh-CN`
- `cta`：一句明确的下一步动作（收藏 / 评论 / 问我 / 点链接找同款）；**不要**把报备披露塞进这里
- `mentions`：品牌官方号或合作方 @handle（若 Brief 指定）
- `location`：可留空

## `caption`

- `body`：**必填**，600–1000 字；2–3 行一段，emoji 点缀，**姐妹化口语**
  - 段落顺序：痛点共鸣 → 使用场景 → 卖点体验 → 结果 / 对比 → CTA
  - 首段前 2 行就要有代入钩子，不要铺垫背景
  - **严禁绝对化用语**：最 / 第一 / 100% / 根治 / 立刻见效 等
  - 医疗、功效、化妆品：不承诺疗效，不使用未验证数据
  - 蒲公英合作/返佣关系在正文内显式披露
- `variants`（可选）：若用户要 A/B，主版放 `body`，备选版 `{label:"B-钩子版", body:"…"}` 放这里；差异化维度建议用反转 / 对比 / 数字型标题（如"用了 30 天我后悔没早买"）
- `tone_notes`：内部语气备忘，一两句即可

## `hashtags`

- `items`：3–10 个，**不带 `#` 前缀**，由渲染端拼接
  - 必含：**品牌词 × 1 + 品类词 × 1 + 人群/场景词 × 1**
  - 剩余名额给长尾词（功效词、节点词、地域词）
- `placement`：`"inline"`（正文末尾）
- `max`：10

## `images`

小红书是图文为主，图决定完播/点赞。

- `style`：整组图的视觉总纲，一段 2–4 句话，覆盖 **色调 / 光线 / 氛围 / 场景类型 / 拍摄感（手机随拍 or 布景 or 真实使用场景） / 文字叠加风格**
- `aspect_ratio`：默认 `"3:4"`（少数长图用 `"9:16"`）
- `items`：**4–8 张**，顺序即图序；每张一条 object：
  - `role`：
    - 第 1 张必为 `"cover"`（封面，带大字标题叠加，决定点击率）
    - 中间为 `"content"`（卖点 / 场景 / 使用演示 / 对比 / 效果图）
    - 最后一张可为 `"closing"`（总结图 / CTA 图 / 合照 / 购买指引，可省略）
  - `prompt`：detailed 英文或中文都可，必须包含 **主体 + 场景 + 构图 + 光线 + 色调 + 风格 + 若有文字叠加需写清楚文案与字体风格**；封面 prompt 必须明示"封面字"（与 `meta.title` 对应）
  - `alt`：一句中文描述，用于无障碍

## 自检清单

- `meta.title` ≤ 20 字且有钩子？
- `caption.body` 无绝对化用语、已按需做合规化改写？
- `hashtags.items` 至少覆盖品牌 × 品类 × 人群/场景？
- `images.items[0].role == "cover"` 且 prompt 里写清了封面字？
- `images.items` 数量与 `role` 分布是否合理（4–8 张）？
