# 小红书 Xiaohongshu —— 撰写规则

## 结构

- **标题**：≤ 20 字；含 emoji + 钩子（数字 / 身份标签 / 反转 / 悬念）
- **正文**：600–1000 字；2–3 行一段，emoji 点缀，**姐妹化口语**
- **段落顺序**：痛点共鸣 → 使用场景 → 卖点体验 → 结果 / 对比 → CTA
- **首段**：前 2 行就要有代入钩子，不要铺垫背景

## 话题

- 3–10 个 `#话题`，放正文末尾
- 必含：**品牌词 × 1 + 品类词 × 1 + 人群/场景词 × 1**
- 剩余名额给长尾词（如功效词、节点词）

## 语气与合规

- 贴合 KOL 的 `tone_tags` / `voice`，第一人称
- **严禁绝对化用语**：最 / 第一 / 100% / 根治 / 立刻见效 等
- 医疗、功效、化妆品合规：不承诺疗效，不使用未验证数据
- 合作报备：按 KOL `no_go_list` 与 Brief 合规要求处理；蒲公英合作需提示报备
- 种草感 > 硬广感；避免"官方口径"式罗列参数

## 版本差异

- **版本 A（稳）**：经验分享型，场景代入 + 使用感受
- **版本 B（钩子）**：反转 / 对比 / 数字型标题（如"用了 30 天我后悔没早买"）

## 输出字段

```
## 小红书 · 版本 {A|B}
- 标题（{字数}字）：…
- 正文（{字数}字）：
  …
- 话题：#… #… #…
- 备注：{风险 / 披露 / 假设}
```
