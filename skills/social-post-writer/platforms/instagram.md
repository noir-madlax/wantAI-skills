# Instagram —— 撰写规则

## 结构

- **Caption 首 125 字 = Hook**：折叠前必须完整表达核心钩子
- **总长度**：150–500 字为宜；短句分行，emoji 适度
- **段落**：每 1–2 行一段，便于移动端阅读

## Hashtags

- 5–15 个；混合 **高热 / 中等 / 长尾** 标签
- 位置：正文末尾，或作为**首条评论**（不影响 caption 干净度）
- 品牌词 + 品类词 + 受众词各 ≥ 1

## Mentions 与披露

- 品牌用 `@handle` mention
- 合作帖加 `#ad` / `#sponsored`，或使用 **Paid Partnership** 标签
- 按 Brief 合规项披露任何返佣 / 赠样关系

## CTA

- 明确**只选一项**：Save / Share / Comment / DM / Link in bio
- CTA 放正文末尾、hashtags 之前

## 语气与语言

- 贴合 KOL `voice`，视觉化短句、生活方式调性
- 默认英文；若 KOL `audience_signals` 指明其他市场语言，按主要受众语言输出

## 版本差异

- **版本 A（稳）**：叙事型 caption + 情绪收束 CTA
- **版本 B（钩子）**：首句悬念/反常识，高强度 hook

## 输出字段

```
## Instagram · 版本 {A|B}
- Caption（{字数}字 / 首 125 字 hook：…）：
  …
- Hashtags：#… #… #…
- CTA：…
- 备注：{披露 / 假设}
```
